# 개인정보처리방침

박승균(이하 "운영자")은 「개인정보 보호법」에 따라 이용자의 개인정보를
보호하고 관련 고충을 신속히 처리하기 위해 다음과 같이 개인정보처리방침을 둡니다.

- 서비스명: 찍고갈래 (영문 `fourcut`, 일본어 「撮ってく？」)
- 시행일: 2026년 10월 26일

## 1. 수집하는 개인정보 항목과 수집 방법

### 1-1. 소셜 로그인 시 (필수)

카카오 또는 구글 계정으로 로그인할 때, 해당 제공자로부터 다음을 전달받습니다.

| 항목 | 필수 여부 | 비고 |
| --- | --- | --- |
| 회원 식별자 | 필수 | 운영자가 발급하는 내부 번호 |
| 로그인 제공자 | 필수 | 카카오 / 구글 |
| 이메일 주소 | 선택 | 제공자가 주지 않으면 수집되지 않음 |
| 닉네임 | 선택 | 위와 같음 |
| 프로필 이미지 주소 | 선택 | 위와 같음 |

이용자가 제공자의 동의 화면에서 선택 항목 제공을 거부해도 서비스를 이용할 수 있습니다.

### 1-2. 서비스 이용 과정에서 생성·수집되는 정보

| 항목 | 수집 시점 | 비고 |
| --- | --- | --- |
| 촬영한 사진 | 촬영 직후 | **얼굴이 포함될 수 있는 이미지** |
| 완성된 네컷 이미지 | 저장·인쇄·QR 발급 시 | 위와 같음 |
| 촬영 과정 영상 | 촬영 시 | 소리는 녹음하지 않습니다 |
| 사진 배치 정보 | 네컷 구성 시 | 어느 사진을 어느 칸에 넣었는지 |

사진·영상이 **서버로 전송되는 경우는 QR로 받기를 눌렀을 때뿐**입니다. 이때 완성된
네컷 이미지와 촬영 영상을 올려 다운로드 주소를 만듭니다.

**QR로 받기를 쓰지 않으면 사진·영상은 기기 밖으로 나가지 않습니다.** 저장·인쇄는
모두 기기 안에서 처리됩니다.

### 1-3. 기기에만 저장되고 서버로 보내지 않는 정보

| 항목 | 저장 위치 |
| --- | --- |
| 로그인 토큰 | 기기 보안 저장소(iOS 키체인 / Android Keystore) |
| 선택한 언어 | 앱 내부 저장소 |
| 완성된 네컷과 영상 | 사진 앱의 "찍고갈래" 앨범 |
| 직접 만든 프레임 | 앱 전용 폴더 |

갤러리 화면은 **이 기기의 앨범만 읽습니다.** 서버에서 가져오지 않으며, 다른
기기에서 찍은 사진은 보이지 않습니다.

## 2. 개인정보의 이용 목적

- 회원 식별 및 로그인 유지
- 네컷 사진·영상 제작과 저장, 인쇄
- QR 다운로드 링크 제공
- 이용자 문의 및 불만 처리

수집한 정보는 위 목적 외에는 이용하지 않으며, 목적이 바뀌면 사전에 동의를
받습니다.

## 3. 보유 및 이용 기간

| 구분 | 기간 |
| --- | --- |
| 회원 정보 | 회원 탈퇴 시 지체 없이 파기 |
| QR로 올린 사진·영상 | 업로드일로부터 7일 경과 시 삭제 |
| 로그인 토큰 | 로그아웃 또는 탈퇴 시 기기에서 삭제 |

관계 법령에서 보존을 요구하는 경우 그 기간을 따릅니다. 현재 서비스는 무료이며
결제 기능이 없어 전자상거래법상 거래 기록 보존 의무는 발생하지 않습니다.

## 4. 개인정보의 제3자 제공

운영자는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 다음은 예외입니다.

- 이용자가 사전에 동의한 경우
- 법령에 따라 수사기관 등이 적법한 절차로 요구하는 경우

### QR 다운로드 링크에 관한 안내

QR로 만든 다운로드 주소를 아는 사람은 누구나 해당 사진·영상을 내려받을 수
있습니다. 링크를 다른 사람에게 전달하면 그 사람도 접근할 수 있으므로, **원하지
않는 사람에게 공유하지 마세요.**

업로드한 사진·영상은 7일이 지나면 삭제되므로, 그 이후에는 링크로도 받을 수
없습니다.

서비스 서버가 일본에 있어, 다음과 같이 개인정보가 국외로 이전됩니다.

| 구분 | 내용 |
| --- | --- |
| 이전받는 자 | Oracle Corporation (Oracle Cloud Infrastructure) |
| 이전되는 국가 | 일본 (도쿄 리전) |
| 이전 일시와 방법 | 서비스 이용 시 네트워크를 통해 수시로 전송 |
| 이전되는 항목 | 회원 정보(회원 식별자, 로그인 제공자, 이메일 주소, 닉네임, 프로필 이미지 주소), QR로 받기를 누를 때 올리는 사진·영상(서버를 거쳐 아래 저장소로 전송) |
| 이전 목적 | 서비스 서버 운영, 회원 정보 보관 |

QR로 올린 사진·영상은 대한민국(서울 리전)에 있는 Amazon S3에 보관됩니다.

국외 이전을 원하지 않으면 회원 탈퇴로 거부할 수 있습니다. 다만 서비스는 위 서버로만
운영되므로, 거부하면 로그인이 필요한 기능을 이용할 수 없습니다.

## 6. 이용자의 권리와 행사 방법

이용자는 언제든지 다음을 할 수 있습니다.

- **개인정보 열람·정정** — 아래 개인정보 보호책임자의 이메일로 요청하면 지체 없이
  처리합니다. 앱에는 따로 조회·수정 화면이 없습니다.
- **회원 탈퇴(삭제)** — 앱의 **설정(톱니) → 계정 → 회원 탈퇴**
- **동의 철회** — 탈퇴로 갈음합니다

탈퇴하면 서버의 회원 정보가 삭제되고, 카카오·구글 연결도 해제됩니다.
**기기의 사진 앱에 저장된 네컷 사진과 영상은 지워지지 않습니다.** 필요하면
사진 앱이나 앱의 갤러리 화면에서 직접 삭제하세요.

## 7. 개인정보의 파기

보유 기간이 끝나거나 목적을 달성하면 지체 없이 파기합니다. 전자적 파일은 복구할
수 없는 방법으로 삭제합니다.

## 8. 만 14세 미만 아동

**만 14세 미만 아동은 회원으로 가입할 수 없습니다.**

「개인정보 보호법」 제22조의2는 만 14세 미만 아동의 개인정보를 처리하려면
법정대리인의 동의를 받도록 정하고 있습니다. 운영자는 해당 동의를 받는 절차를
두고 있지 않으므로, 만 14세 미만 아동의 개인정보를 수집하지 않습니다.

만 14세 미만 아동이 가입한 사실을 알게 된 경우 해당 계정과 수집된 개인정보를
지체 없이 삭제합니다. 법정대리인은 아래 연락처로 삭제를 요구할 수 있으며,
요구가 있으면 지체 없이 처리합니다.

## 9. 개인정보의 안전성 확보 조치

- 서버와의 통신은 전 구간 HTTPS(TLS)로 암호화합니다.
- 로그인 토큰은 기기의 보안 저장소에 보관합니다.
- 서버는 로그인 갱신 토큰의 원문을 저장하지 않고 해시값만 보관합니다.
- 반복된 로그인 시도를 제한해 무단 접근을 막습니다.
- 데이터베이스와 애플리케이션은 외부에서 직접 접속할 수 없게 하고, 웹 서버를
  통해서만 접근하게 합니다.
- 보관한 사진·영상은 공개되지 않으며, 기간이 정해진 다운로드 주소로만 받을 수
  있습니다.
- 서버 접속 정보와 비밀키는 소스 코드와 분리해 관리합니다.
